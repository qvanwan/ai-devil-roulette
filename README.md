# 🎰 AI 恶魔轮盘赌 (AI Devil Roulette)

一个基于大语言模型（LLM）的**纯终端多智能体博弈游戏**。6 个 AI 坐在同一张牌桌上，为了活到最后，它们会撒谎、结盟、背刺，甚至因为“幻觉”把自己一枪崩了。

本项目从最初的 4 人局，经过多个版本的疯狂迭代，最终演变成了一个拥有 **数十种子弹和战术道具**、**严密防幻觉机制**的赛博斗蛐蛐引擎。

## 🚀 如何运行

注意：请在终端前台运行并输入 API Key（暂不支持后台静默运行）。

只需要 Python 环境和 `requests` 库：

```bash
# 1. 安装依赖
pip install requests

# 2. 运行游戏 (假设代码文件名为 roulette.py)
python roulette.py

# 3. 在终端粘贴你的 API Key（仅在内存中运行，绝不落盘）
```

> **📱 纯手机终端 (Termux/Podroid) 或纯命令行无编辑器运行方案：**
> 如果你没有本地代码编辑器，可以直接在终端中输入以下命令，一键生成文件并运行：
> ```bash
> cat << 'EOF' > roulette.py
> # 这里粘贴完整的 Python 代码
> EOF
> python3 roulette.py

(注意：结尾的 EOF 必须单独占一行且不能有空格)

## 📦 版本选择指南 (Version Guide)

本项目目前提供三个并行版本，请根据你的 Token 预算和对局偏好自行选择：

### ☢️ v20.7 绝命辐射版 (推荐)
*   **运行文件**：`roulette_radiation_v20.7.py` 
*   **特点**：第 6 轮起加入“绝命辐射”机制。环境逼着 AI 交火，子弹伤害翻倍，节奏极快，节目效果爆炸。
*   **适合谁**：所有玩家，Token 消耗适中（单局 2万~3万），拒绝膀胱局。

### 🩺 v20.6 医学奇迹版 (Token 杀手)
*   **运行文件**：`roulette_medical_v20.6.py`
*   **特点**：拥有 29 种道具、16 种子弹。拥有极强的医疗与反转机制，AI 会疯狂拉扯，极其考验数值平衡。
*   **适合谁**：拥有无限 Token 额度的大佬，或想看 AI 打 15 轮膀胱局的吃瓜群众。*(警告：单局可能消耗 7万+ Token)*

### 💀 v18.7 硬核纯战版
*   **运行文件**：`roulette_classic_v18.7.py`
*   **特点**：没有医疗箱、没有反转弹，纯正的火力对决。拥有完善的“防幻觉机制”和“硬币叠甲”，TTK（击杀时间）极短，一发入魂。
*   **适合谁**：想体验最硬核、最原汁原味的“恶魔轮盘赌”，喜欢看 AI 快速暴毙的玩家。Token 消耗极少。


💡 提示：当前默认使用智谱 AI 的 glm-4-flash 模型。

👉 怎么获取 Key？ 请前往 智谱 AI 开放平台 注册并申请 API Key。

👉 想换模型？ 如果你想用 OpenAI、DeepSeek 或本地 Ollama，直接修改代码开头的 URL 和 MODEL 变量即可。
