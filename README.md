# 🎰 AI 恶魔轮盘赌 (AI Devil Roulette)

一个基于大语言模型（LLM）的**纯终端多智能体博弈游戏**。6 个 AI 坐在同一张牌桌上，为了活到最后，它们会撒谎、结盟、背刺，甚至因为“幻觉”把自己一枪崩了。

本项目从最初的 4 人局，经过 18 个版本的疯狂迭代，最终演变成了一个拥有 **14 种子弹**、**23 种战术道具**、**严密防幻觉机制**的赛博斗蛐蛐引擎。

## 🚀 如何运行

只需要 Python 环境和 `requests` 库：

```bash
# 1. 安装依赖
pip install requests

# 2. 运行游戏 (假设代码文件名为 roulette.py)
python roulette.py

# 3. 在终端粘贴你的 API Key（仅在内存中运行，绝不落盘）
```

💡 提示：当前默认使用智谱 AI 的 glm-4-flash 模型（免费且极速）。如果你想用 OpenAI、DeepSeek 或本地 Ollama，直接修改代码开头的 URL 和 MODEL 变量即可。

⚠️ 免责声明：本项目纯属技术娱乐和 AI 行为观察实验，游戏内的“赌博”、“背刺”机制不代表任何现实建议。
